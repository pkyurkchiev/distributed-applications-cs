# Plant Shop

Факултетен номер - 2301261063
Име на проекта - Plant shop
PlantShop е уеб приложение, което предоставя управление на данни за растения, почви и торове. Системата поддържа три нива на достъп – гост, потребител и администратор – и включва функционалности като регистрация, вход, търсене, сортиране, CRUD операции и управление на роли.


Уеб приложение, разработено с ASP.NET Core MVC и MySQL. 
Системата управлява информация за растения, почви и торове. 
Поддържа три нива на достъп: Guest, User и Admin.  
Гостът може да разглежда данни, User може да търси/сортира/страницира, 
а Admin има пълен CRUD достъп и управление на роли заедно с всички функционалности на приложението.


## Инсталация

### 1. Изисквания
- IDE - Visual Studio 2022
- .NET SDK 8.0
- MySQL server и MySQL Workbench (за улеснение) - 8.x

### 2. Връзка с база данни
Създава се и въмква в `appsettings.json` - задава се потребител и парола

Пример:
{
    "ConnectionStrings": {
        "DefaultConnection": "Server=localhost;Port=3306;Database=PlantShopDb;User=root;Password=1234;"

    },
    "Logging": {
        "LogLevel": {
            "Default": "Information",
            "Microsoft.AspNetCore": "Warning"
        }
    },
    "AllowedHosts": "*"
}

## Стартиране на проекта

1. Клонира се проекта
2. Отваря се решението `PlantShop.sln` във Visual Studio
3. Трябва MySQL да работи
4. Проверка за връзката към базата в `appsettings.json`
5. Стартиране - Run
